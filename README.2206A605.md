## 🚀 Overview

This repository provides a base GUI framework for students to develop and integrate machine learning methods. The GUI is built using PyQt6 and supports various classical machine learning and deep learning techniques.

### Additions

 GaussainNB section has been added to the classification part
 Loss options are added 
    For regression as
     Mean Square Error
     Mean Average Error
     Huber loss
   For Classification
    Cross Entrophy
    Hinge Loss
 Missing value handling has been added
   Interpolation
   Mean Imputation
   Forward/Backward Fill
